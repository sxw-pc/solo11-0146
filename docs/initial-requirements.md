# 首版需求与边界

三个独立对象为公益岗位及报名承诺、志愿者技能资格、现场服务时数。十个业务决定涵盖公告版次、缩员重排、截止候补、凭证来源、技能匹配、撤销派工、签到站点、重叠时数、主管独立复核和缺岗责任。跨账路径分别是缩员改变候补和组织责任、技能撤销冻结派工与时数、签到跨公告窗口只计算有效交集。

未来扩展：跨组织时数互认、未成年人监护同意、应急岗位补训、交通补贴、多站点巡回、申诉听证、匿名统计。首版不实现这些对象，也不把测试数据视为真实服务证明。

公益成效归因已在受益人评估子系统落地：冻结邀请清单、双签交付单、独立问卷与签约合同四种原件支撑意向治疗效应与依从家庭效应两种口径，不能识别的估计留待核而不删改历史报告。
